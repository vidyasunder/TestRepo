# Troubleshooting

The Help Center has a dedicated troubleshooting resource. In GitBook, troubleshooting can be organized by symptom, product, and likely owner.

| Symptom                           | First check                                                        | Escalation                                             |
| --------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------ |
| Images look darker than expected  | Compare imagery type, date, and display settings.                  | Product support if the issue affects multiple surveys. |
| Location search returns no result | Try alternate address formatting or coordinates.                   | Support if coverage should exist.                      |
| Export image is pixelated         | Confirm export size, source imagery, and zoom level.               | Support if source resolution seems wrong.              |
| API key does not work             | Confirm key validity, application association, and request format. | Administrator or support depending on account setup.   |
