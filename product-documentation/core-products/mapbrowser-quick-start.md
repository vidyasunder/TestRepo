# MapBrowser quick start

MapBrowser is the web-based mapping and measurement platform for exploring Nearmap high-resolution aerial imagery in 2D and 3D.

## Common jobs

| Job                | What the user needs                                                                    |
| ------------------ | -------------------------------------------------------------------------------------- |
| Look up a location | Search by address, place, or coordinate and confirm available imagery dates.           |
| Compare captures   | Use imagery dates to inspect change over time.                                         |
| Organize work      | Create projects so site research and markups can be shared with the team.              |
| Export evidence    | Use screenshots, reports, or exports when findings need to move into another workflow. |
